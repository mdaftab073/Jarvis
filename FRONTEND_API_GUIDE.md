# Frontend API Guide

Generated from the registered FastAPI OpenAPI schema. Contract freeze: 2026-10-03.

## Base URL and contract

- Local base URL: `http://localhost:8000`; deployed base URL is the API origin supplied by the deployment.
- All successful application operations use `{ "success": true, "data": ... }`; all API errors use `{ "success": false, "error": { "code": "...", "message": "..." } }`.
- JSON success response schemas below include the envelope and the declared `data` model. `Any` means the runtime envelope is present but OpenAPI does not constrain the data shape.
- Unless marked public, `/api/*` operations require `Authorization: Bearer <access_token>`. The browser origin must be present in the backend `ALLOWED_ORIGINS` setting.
- Authenticated users must use the student represented by the token; do not treat client-supplied student IDs as identity.
- Use `multipart/form-data` where listed (for example, PDF uploads); do not JSON-encode a file upload.
- Interactive schema: `/openapi.json`; Swagger UI: `/docs`.

## Common error responses

Every operation declares the shared `ErrorResponse` shape in OpenAPI. Only applicable errors occur for a particular operation; custom domain codes may be returned for the same status.

| HTTP status | Typical code | Meaning |
|---|---|---|
| 400 | `bad_request` | Request cannot be processed. |
| 401 | `unauthorized` | Missing or invalid access token, or authentication failure. |
| 403 | `forbidden` | Authenticated caller lacks access; metrics additionally requires `X-Admin-Token`. |
| 404 | `not_found` | Resource is absent or outside caller scope. |
| 409 | `conflict` | State conflict or duplicate operation. |
| 413 | `payload_too_large` | Upload exceeds configured size. |
| 422 | `validation_error` | Request validation failed. |
| 429 | `rate_limited` | Rate limit exceeded. |
| 500 | `internal_server_error` | Unexpected server error. |
| 503 | `http_503` or domain-specific code | Dependency/authentication service unavailable. |

Error shape: `{ "success": false, "error": { "code": "...", "message": "..." } }`.
